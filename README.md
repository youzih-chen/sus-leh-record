# LEH 資料紀錄程式（LEH Recorder）

本程式為基於 Python 與 Tkinter 開發之桌面應用程式，專用於牙齒形態量測、線性釉質發育不全（LEH）觀察紀錄及影像編號管理。系統支援依據牙齒磨耗程度自動推算年齡分期，並提供結構化備份與表格匯出功能。

---

## 一、啟動方式

### 方式一：使用獨立執行檔（建議，無須安裝執行環境）
1. 前往本專案頁面右側之 **Releases**（發行版本）。
2. 下載最新版本之 `leh_record.exe`。
3. 雙擊 `leh_record.exe` 即可啟動程式，無須另外安裝 Python。

### 方式二：由原始碼執行（需具備 Python 3.8 以上版本）
本程式僅相依於 Python 標準函式庫，無須額外安裝第三方套件。請於專案目錄下開啟終端機並執行下列指令：
```bash
python leh_record.py
```

---

## 二、初始化設定

1. **指定工作目錄與資料檔案**：
   - **Create New Folder（建立新資料夾）**：選定目標目錄後，系統將自動建立以當日日期命名之表格檔案（`LEHrec_YYYYMMDD.csv`）。
   - **Open Existing File（開啟既有檔案）**：選取既有之 `.csv` 檔案，以載入歷史紀錄並接續作業。
2. **設定脈絡欄位（`Context`）**：
   - 建立新專案時，系統將提示輸入自訂之脈絡子欄位（以半形逗號分隔，例如：`Site, Layer`），確認後即完成欄位配置。

## 三、介面欄位與功能說明

### 1. 基本資料區（Basic Information）
- **`Sample ID`**：標本編號（必填）。同一生物個體之多顆牙齒請填入相同之 `Sample ID`。
- **`Jaw Type`**：上下顎別，請由下拉選單選取 `U`（上顎）、`L`（下顎）或 `un`（無法判定）。
- **`Tooth Type`**：牙齒類型，請由下拉選單選取（乳齒 `di1`–`dp4`、恆齒 `I1`–`M3`，必填）。
- **`Wear Level`**：牙齒磨耗等級（請輸入對應之數值分級）。
- **`Age Group` 與 `Pause Auto` 核取方塊**：
  - 輸入 `Tooth Type`、`Jaw Type` 與 `Wear Level` 後，系統將自動比對年齡分期表並填入對應分期（`A`–`G`）。
  - **同個體年齡分期交集**：若同一 `Sample ID` 已有其他已儲存之牙齒紀錄，系統將自動對所有相關牙齒之年齡分期取交集，以收斂出更精確之 `Age Group`；儲存當前紀錄時，亦會同步更新先前同 `Sample ID` 紀錄之 `Age Group`。
  - **分期衝突處理**：若同個體不同牙齒所推算之年齡分期無交集，系統將維持當前牙齒之推算區間，並於視窗下方狀態列顯示衝突提示。
  - **暫停自動推算（`Pause Auto`）**：勾選 `Pause Auto` 後，系統將暫停自動覆寫，供使用者於 `Age Group` 欄位手動輸入或修訂數值；取消勾選後即恢復自動推算。

### 2. 量測與 LEH 紀錄區（Measurements / LEH Records）
- 各量測項目皆配置三組輸入欄位，系統將於右側即時計算平均值（輸入全形句號 `。` 將自動轉換為半形小數點 `.`）。
- 若同一位置包含多筆 LEH 觀察紀錄，可點擊該列右側之 **`+`** 按鈕動態擴充輸入列。

### 3. 備註與影像編號區（Other Information / Photo）
- **`Notes`、`Pathology`**：提供自由文字輸入，用於記錄補充說明與病理特徵。
- **影像編號**：預設包含 `Buccal`、`Lingual`、`Occlusal` 三種固定視角，亦可點擊 **`+`** 按鈕新增自訂影像類型與編號欄位。

## 四、操作按鈕說明

- **`Save`**：儲存當前表單資料至系統紀錄並寫入暫存檔，隨後清空表單以利後續輸入。
- **`Previous Record`**：載入前一筆已儲存之紀錄，以供檢視或修訂。
- **`NEXT(same)`**：儲存當前紀錄，並**保留基本資料與影像欄位**，便於接續登錄同一 `Sample ID` 個體之下一顆牙齒。
- **`NEXT(another)`**：儲存當前紀錄，僅保留自訂之脈絡欄位（`Context`），清空其餘欄位以開始登錄下一個體。
- **`New Record`**：捨棄當前未儲存之輸入內容，重置表單以開始全新紀錄。
- **`Export CSV`**：將所有已儲存之紀錄正式匯出為 `.csv` 表格檔案，並同步更新中繼資料檔。

> **既有紀錄之修訂方式**
> 於視窗左側 **Previous Records** 清單中雙擊欲修訂之項目即可載入表單；編輯完成後點擊 **`Save`**，系統將直接覆寫更新該筆原始紀錄，不致產生重複項目。

## 五、輸出檔案結構

於選定之工作目錄下，系統將產生並維護下列檔案與子目錄：

```text
工作目錄/
├── LEHrec_YYYYMMDD.csv       # 執行 Export CSV 後匯出之完整資料表
├── snapshots/
│   ├── index.json            # 左側歷史清單之紀錄索引檔
│   └── R1_S1_<SampleID>.json # 各筆紀錄之獨立 JSON 備份檔
└── metadata/
    └── metadata.pkl          # 供再次開啟專案時還原作業狀態之中繼資料檔
```
